# Protomotive Car Care Studio — Demo Website

A high-performance automotive detailing and paint protection studio website built with Next.js 14+ (App Router), Tailwind CSS v4, GSAP, and Lenis smooth scroll.

## Architecture
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS v4 + Obsidian & Carbon Precision Studio Palette
- **Smooth Scroll**: Lenis + GSAP ScrollTrigger
- **Business Configuration**: Centralized `lib/business-config.ts` source of truth for all business identity, services, locations, and ratings.

## Getting Started
```bash
npm install
npm run dev
```
